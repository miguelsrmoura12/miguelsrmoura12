## Projetos

### Sistema de Controle de Solicitações Corporativas (SCSC)

Aplicação CLI em Python para o gerenciamento centralizado de demandas internas. Permite cadastrar solicitantes, abrir chamados com classificação automática de prioridade, atualizar status e gerar estatísticas operacionais, com MySQL para persistência dos dados.

**Stack:** Python · MySQL

### Sistema de Atendimento de Pronto-Socorro (SAPS)

Projeto Integrador II, PUC-Campinas, 2º semestre de 2026. Sistema web que organiza o fluxo de atendimento de um pronto-socorro, da chegada do paciente à recepção até a finalização do atendimento médico. Reúne o que aprendi em Programação para Web, Banco de Dados, Processos de Engenharia de Software e Estrutura de Dados e Algoritmos.
